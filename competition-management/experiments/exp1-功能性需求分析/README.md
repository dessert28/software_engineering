## AI 参与范围声明

> 课程要求如实说明 AI 参与范围。本节供报告正文直接引用。

| 环节 | 人工 | AI 辅助 |
|---|---|---|
| 选题 | 提出候选、投票决定 | 列举赛道方向、分析可行性 |
| 访谈 | **全部人工完成** | 无 |
| 需求描述表 | 判断取舍、确认优先级 | 生成初稿条目、检查遗漏 |
| 原型 | 确定页面结构、决定交互 | 生成 HTML/CSS 代码 |
| SRS 章节 | **核心章节人工编写**（`srs_manual.md`） | 生成对照稿（`srs_ai.md`），人工核对后不直接采用 |
| 反思 | 人工撰写 | 无 |

**结论**：AI 用于扩展思路、生成代码骨架、检查遗漏；需求取舍、访谈、SRS 核心章节由人工完成。具体提示词与核对过程见 `ai_log.md` 与 `ai_audit.md`。

## 从实验一看出的两个问题

写实验二、三时需要继续处理：

1. **功能需求有 14 条，但完整需求表最终演化成 28 条（FR-001～FR-028）**。实验一版本聚焦主链路，V1/V2 的申诉、导出、统计在第 11～12 周才补进 [功能需求](../../docs/functional-requirements.md)。
2. **原型只有 1 个页面**（首页），个人中心的「我的竞赛」四种状态、评审工作台都没有原型。这部分在实验三的 MVP 设计里要补。
